PERFECT STUDY SPACE
Project reference and manual acceptance guide
New capabilities · Side-by-side checks

How the new features work
and how to test them

The original staff management app is the baseline. This guide covers the newer PSS-AI additions, ML capabilities, student products, operating tools and controls.

Live-test prerequisite: confirm Cloudflare Pages publishes the Vite dist folder. The earlier read-only check of perfectstudyspace.pages.dev served raw JSX. Live migrations, function versions and secrets have not been verified.
Before you start

Verify migrations 001–072, current api / agent / cron functions, correct backend project, required secrets and private storage. Enable one setting and its dependencies, then reload.

Use staging for invented payments, forced jobs, concurrency tests and fabricated history. A frontend preview can still point at the production backend.

Keep pssai_agent_shadow = on when first testing either AI chat. Off permits direct replies and allowed chat actions.

Local evidence: 109 unit tests passed; 29 server suites passed via Deno directly; production build passed. Server tests used simulated Supabase and AI.
